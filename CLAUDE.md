# ticket-maker

Internal tool for the Comedy Castle office. Reads the club's upcoming shows
from comedycastle.com, lets an employee review them, and produces print-ready
ticket PDFs.

**Before changing how anything works, read `.claude/PRODUCT-NOTES.md`.** It
holds the real-world office behaviour, every decision made so far and why, and
the questions still open. Where it and the code disagree, that file wins.

Record every judgement call you make in its decision log.

`README.md` covers the build, the schedule parser, and the full ticket
specification measured off the office's own tickets.
